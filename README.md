# Esports Manager 2026 — มอดภาษาไทย

มอดภาษาไทยสำหรับ **Esports Manager 2026 (Steam / Windows)** แบบ runtime ผ่าน
MelonLoader โดยไม่แก้ไข asset ต้นฉบับของเกม

Repository นี้ใช้สำหรับแจกไฟล์พร้อมเล่นเท่านั้น และไม่มี source code ของมอด

> เวอร์ชันล่าสุด: **v1.0.19**
> อัปเดตแพ็กคำแปลจาก Steam build `25257320`; ใช้ MelonLoader `0.7.3`

## ดาวน์โหลดพร้อมเล่น

ดาวน์โหลดไฟล์ `EsportsManager2026.Thai-v1.0.19-Full.zip` จากหน้า
[Releases](../../releases/latest) แพ็กนี้รวม **MelonLoader v0.7.3 x64** จาก
[LavaGang](https://github.com/LavaGang/MelonLoader) ไว้แล้ว ไม่ต้องไปดาวน์โหลดอะไรเพิ่มเอง

วิธีติดตั้ง:

1. ปิดเกม Esports Manager 2026
2. แตก ZIP ออกมาไว้ที่ใดก็ได้
3. ดับเบิลคลิก `Install-ThaiMod.cmd`
4. ตัวติดตั้งจะหา Steam Library และลง MelonLoader กับมอดไทยให้อัตโนมัติ
5. เปิดเกมผ่าน Steam ตามปกติ

หากหาเกมไม่พบ ตัวติดตั้งจะให้เลือกโฟลเดอร์ที่มี `EsportsManager.exe` การเปิดเกม
ครั้งแรกอาจใช้เวลาประมาณ 1-3 นาทีเพื่อสร้าง IL2CPP interop แพ็ก v1.0.19 รวม
Cpp2IL ที่รองรับ Unity metadata 107 และ dependency ที่จำเป็นไว้แล้ว

## ขอบเขตคำแปล

- Unity String Tables 5,311 รายการ (ตัดคีย์กำกวมที่อาจเป็นชื่อผู้เล่นออกจากการแปล runtime)
- อีเมลและข้อความจำลอง 1,635 รายการ พร้อมเทมเพลตข่าวแบบไดนามิก
- บทสนทนา 1,144 รายการ รวมข้อความที่ประกอบแบบไดนามิก
- Loading tips ครบ 100 ประโยค
- รองรับ SmartFormat, placeholder, rich text และ gender token
- ฟอนต์ไทย TextMeshPro พร้อมชื่อวันและเดือนภาษาไทย
- ซ่อมอีเมลเก่าในเซฟทั้งกล่องอัตโนมัติเมื่อเปิดกล่องจดหมายครั้งแรก
- ซ่อมประวัติแชตภาษาอังกฤษหรือข้อความผสมในเซฟเดิมเมื่อเปิดหน้าสนทนา
- แปลอีเมล/แชตที่เกมประกอบข้อความใหม่ระหว่างเล่น พร้อมคง placeholder และตัวเลขของเกม
- อัปเดต String Table จาก Steam build `25257320` และข้อความ UI ที่เพิ่มในแพตช์
- แปลหน้าแบนแผนที่ เลือกฝ่าย กลยุทธ์ ครึ่งแรก/ครึ่งหลัง ต่อเวลา และข้อความจำลองการแข่งขัน
- ป้องกันชื่อผู้เล่น `PR`, `Max` และ `max` ถูกแปลเป็นคำทั่วไปจนสีหรือฝั่งใน Kill Feed ผิด
- แก้ clean install ค้างที่ `Unsupported metadata version ... got 107`

ชื่อทีม ผู้เล่น แบรนด์ รายการแข่งขัน ชื่อแผนที่ และคำย่อที่อาจเป็นชื่อผู้เล่น
จะคงรูปเดิมโดยเจตนา

## ถอนการติดตั้ง

ปิดเกม แล้วดับเบิลคลิก `Uninstall-ThaiMod.cmd` ตัวถอนติดตั้งจะลบมอดไทยให้อัตโนมัติ
และจะลบ MelonLoader ที่แพ็กนี้ติดตั้งให้เมื่อไม่พบมอดหรือปลั๊กอินอื่น หากผู้เล่นมี
มอดอื่นอยู่ ระบบจะเก็บ MelonLoader และไฟล์ของมอดอื่นไว้

## แก้ปัญหาเบื้องต้น

- ตรวจว่าเกมปิดอยู่ระหว่างติดตั้งหรืออัปเดตมอด
- แตก ZIP ออกมาก่อน ห้ามเปิดตัวติดตั้งจากภายใน ZIP โดยตรง
- ครั้งแรกให้รอจน MelonLoader สร้างโฟลเดอร์ `MelonLoader/Il2CppAssemblies` เสร็จ
- หากอัปเดตจาก v1.0.11 ตัวติดตั้งจะปิดเฉพาะ Cpp2IL รุ่นเก่าที่ค้างอยู่ให้อัตโนมัติ
- Log อยู่ที่ `MelonLoader/Latest.log`
- หากเกมอัปเดตแล้วข้อความใหม่ไม่เป็นไทย กรุณาเปิด Issue พร้อมภาพและข้อความจาก log
